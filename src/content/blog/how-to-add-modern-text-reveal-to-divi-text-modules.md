Reveal text character by character!
<p>If you're looking for a way to catch your website users' attention, this text reveal animation is a great option. While Divi does come with animations out of the box, this animation, which animates each letter one at a time, is not included. Follow these steps and you'll be able to easily apply the animation to any Divi text module on your site. </p>
<h2>Step 1: Purchase the layout from the Divi Marketplace</h2>
<p>Go to the <a href="https://www.elegantthemes.com/marketplace/text-reveal-animation/" rel="noopener" target="_blank">Divi Marketplace</a> to purchase and download the official Text Reveal layout.</p>
<h2>Step 2: Upload JSON file to Divi Library</h2>
<p>Go to your WordPress Dashboard &gt; Divi &gt; Divi Library. At the top, click 'Import &amp; Export'. Go to the Import tab, upload the extracted .JSON file, and upload to the library.</p>
<img height="731" loading="lazy" src="/images/2022/10/text-reveal-letter-by-letter-for-divi.webp" width="800"/><h2>Step 3: Add to page</h2>
<p>On a new or existing page, upload the newly saved Divi layout to the page. For more information on adding a layout from the Divi library, refer to Elegant Theme's documentation:</p>
<ul>
<li>https://www.elegantthemes.com/documentation/divi/divi-library/</li>
<li>https://www.elegantthemes.com/documentation/divi/library-import/</li>
</ul>
<h2>Step 4: Use Animation</h2>
<p>To use the animation, add "reveal up" or "reveal down" to any text module. You can do this by clicking the text module's settings, going to the Advanced tab, and typing in the CSS Class input field.</p>
<p>If you'd like to use this animation on multiple pages, you'll need to make sure that the content inside the layout's Code module is added to each page manually, or simply added to &lt;body&gt; section (found by going to Divi &gt; Integration &gt; 'Body').</p>
